## Key Visual Hierarchy

1. **Product Image** (40% height) — First impression
2. **Trust Badges** (overlay) — Immediate value signals
3. **Clean Title** (2 lines max) — Readable, no spam
4. **Rating & Social Proof** (1 line) — Credibility
5. **⭐ Total Landed Cost Box** (gradient bg) — Hero element (biggest font)
6. **Action Buttons** (primary CTA) — Conversion driver
7. **Merchant Badge** (bottom) — Final trust signal

| Discount Badge | 🔴 Red | Urgency |
| Price Box | Gradient Primary | Focus |

## Responsive Behavior

### Mobile (375px)
- Badges: 2 per row max
- Title: 2 lines
- Price: 2xl font (scaled down from 3xl)
- Buttons: Stack vertically

### Tablet (768px)
- Badges: 3 per row
- Title: 2 lines
- Price: 3xl font
- Buttons: Horizontal row

### Desktop (1024px+)
- Badges: All visible
- Title: 2 lines
- Price: 3xl font
- Buttons: Horizontal row + hover effects
