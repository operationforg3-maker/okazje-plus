## 📝 Konwencje dokumentacji

### Nazewnictwo
- Nazwy plików po polsku (wyjątek: nazwy technologii/API)
- Pliki w `updates/` używają formatu: `YYYY-MM-DD-opis-zmiany.md`
- Milestone summaries: `MX_COMPLETION_SUMMARY.md`

### Organizacja
- Nowe dokumenty umieszczaj w odpowiednim katalogu tematycznym
- Stare dokumenty przenoś do `archive/` gdy tracą aktualność
- Aktualizuj INDEX.md przy dodawaniu większych dokumentów
- Pliki audytowe NIE są modyfikowane retroaktywnie — dodawaj nowe zamiast edytować stare

### Dodawanie nowego dokumentu
1. Wybierz odpowiedni katalog tematyczny
2. Utwórz plik z opisową nazwą
3. Jeśli to zmiana inkrementalna → użyj `updates/` z datą
4. Dodaj link w odpowiedniej sekcji tego indeksu
5. Zaktualizuj README.md jeśli dokument jest kluczowy
