## 🔍 Kiedy sięgać do archiwum?

Dokumenty w archiwum mogą być przydatne gdy:

1. **Badasz historię projektu** – chcesz zrozumieć jak ewoluowała platforma
2. **Analizujesz decyzje techniczne** – audyty zawierają uzasadnienia dla wyborów architektonicznych
3. **Rozwiązujesz problemy** – stare raporty bugów mogą zawierać informacje o znanych problemach
4. **Piszesz dokumentację** – możesz czerpać inspirację z poprzednich dokumentów
